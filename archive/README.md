# Observer Archive

This tree contains historical Observer implementations and research records.

Nothing under `archive/` is part of the active runtime or current evidence pipeline. The active system lives in `src/runtime_lab/`; reusable experiment runners live in `experiments/`; offline analyzers live in `analysis/`; and operational tools live in `tools/`.

## Contents

- `controller/` — the archived closed-loop controller arc and its implementation.
- `prototypes/` — earlier hysteresis, observability, and intervention prototypes.
- `analysis/` — superseded analyzers retained for historical reproduction.

Historical results remain valuable as context, but current claims must follow the repaired contracts documented under `docs/`.
